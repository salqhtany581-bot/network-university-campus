Campus Network Design – Cisco Packet Tracer
📌 Overview

This project demonstrates the design and simulation of a campus network using Cisco Packet Tracer. The network is designed to connect multiple departments and provide efficient communication between devices.

🎯 Objectives
Design a structured campus network.
Configure routers and switches.
Implement VLANs to separate departments.
Configure IP addressing and inter-VLAN routing.
Test connectivity between network devices.
🛠️ Tools & Technologies
Cisco Packet Tracer
Routers and Switches
VLANs
IP Addressing
Inter-VLAN Routing
⚙️ Network Features
Organized network topology.
Communication between different departments.
Logical network segmentation using VLANs.
Efficient and reliable connectivity.
🧪 Testing

Network connectivity can be verified using the ping command and simulation tools in Cisco Packet Tracer.

📁 Project Files
Campus_Network.pkt – Cisco Packet Tracer project file.
🚀 How to Use
Download or clone this repository.
Open the .pkt file using Cisco Packet Tracer.
Explore the network topology and device configurations.
Test connectivity between devices.
